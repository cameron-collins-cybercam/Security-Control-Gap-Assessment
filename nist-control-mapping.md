# Security Framework Mapping

This document demonstrates how security controls align with common cybersecurity frameworks.

---

## Access Control

NIST Control: AC-2  
Description: Account management policies ensure proper identity lifecycle management.

Example Implementation:
Role-based access control (RBAC) using Azure Active Directory.

---

## Authentication

NIST Control: IA-2  
Description: Identification and authentication requirements.

Example Implementation:
Multi-factor authentication for administrative accounts.

---

## Logging

NIST Control: AU-2  
Description: Logging and monitoring security events.

Example Implementation:
Centralized logging platform with alerting capabilities.
