# Security Control Gap Assessment Project

This project demonstrates how cybersecurity Governance, Risk, and Compliance (GRC) teams evaluate security controls, identify control gaps, and recommend mitigation strategies.

The purpose of this project is to simulate a real-world security control assessment aligned with common security frameworks such as:

- NIST Cybersecurity Framework (CSF)
- ISO 27001
- CIS Critical Security Controls

This repository contains example documentation used during a security control review.

---

## Project Objectives

• Identify key security controls within an enterprise environment  
• Evaluate the effectiveness of implemented security controls  
• Identify potential control gaps or weaknesses  
• Document security risks and recommended mitigation strategies  
• Demonstrate how security findings are documented for compliance and audit readiness

---

## Example Security Domains Evaluated

- Identity and Access Management
- Multi-Factor Authentication
- Network Security
- Logging and Monitoring
- Incident Response
